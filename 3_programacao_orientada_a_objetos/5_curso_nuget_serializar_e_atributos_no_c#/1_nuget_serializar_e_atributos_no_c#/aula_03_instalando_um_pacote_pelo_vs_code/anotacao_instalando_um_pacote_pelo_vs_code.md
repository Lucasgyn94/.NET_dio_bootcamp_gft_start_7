# Instalando um pacote pelo VS Code
* Podemos instalar um pacote do Nuget pelo terminal do VS Code, para isso vamos até o site: 
```
nuget.org
```
* escolhemos o nosso pacote, no nosso caso será o __Newtonsoft.Json__, pres
ente no link: 
```
https://www.nuget.org/packages/Newtonsoft.Json/13.0.4-beta1
```
* e então pegamos o script na aba .NET CLI: 
```
$dotnet add package Newtonsoft.Json --version 13.0.4-beta1
```
