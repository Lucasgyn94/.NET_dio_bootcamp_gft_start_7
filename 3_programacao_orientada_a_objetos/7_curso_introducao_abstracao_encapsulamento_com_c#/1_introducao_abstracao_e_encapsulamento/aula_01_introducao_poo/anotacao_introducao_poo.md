# O que é a POO
* A POO é um paradigma de programação, ou seja, corresponde a uma técnica de programação para um fim específico.

* Dentro dessa técnica, existem quatro pilares:
  - Abastração
  - Encapsulamento
  - Herança
  - Polimorfismo

* O principal conceito da POO são classes e objetos.
* Uma classe é a representação/molde de um objeto da vida real.
* O objeto é a própria classe concretizada
