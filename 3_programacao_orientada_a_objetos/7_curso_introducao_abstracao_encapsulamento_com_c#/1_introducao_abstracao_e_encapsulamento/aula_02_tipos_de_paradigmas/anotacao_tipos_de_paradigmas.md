# Paradigma de programação
* Um paradigma nada mais é do que um modelo de técnicas, estrutura e formas de solucionar um problema.
* Paradigma de programação é diferente de linguagem de programação.
* Uma linguagem de programação implementa um ou mais paradigmas.

## Tipos de Paradigmas
* Alguns paradigmas conhecidos são:
  - Programação Orientada a Objetos
  - Programação estruturada
  - Programação imperativa
  - Programação procedual
  - Programação orientada a eventos
  - Programação lógica
