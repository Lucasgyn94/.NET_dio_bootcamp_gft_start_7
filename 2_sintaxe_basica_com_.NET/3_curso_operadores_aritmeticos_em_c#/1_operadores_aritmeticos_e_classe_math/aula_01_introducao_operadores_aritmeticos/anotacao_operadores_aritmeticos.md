# OPERADORES ARITMÉTICOS
* Assim como na matemática, são símbolos especiais utilizados
para realizar cálculos matemáticos com valores númericos.

Operador	Operação	Exemplo em C#		Resultado
+		Adição		int resultado = 10 + 5;	15
-		Subtração	int resultado = 10 - 5;	5
*		Multiplicação	int resultado = 10 * 5;	50
/		Divisão		int resultado = 10 / 5;	2
%		Resto (Módulo)	int resultado = 10 % 3;	1
++		Incremento	resultado++		+1
--		Decremento	resultado--		-1
