# O Laço while (Enquanto)
* O laço while executa um bloco de código repetidamente enquanto uma expressão booleana especificada for true. A condição é testada antes de cada execução do laço.
* E ideal para situações em que __não sabemos de antemão quantas vezes o bloco de código precisa ser executado.__

## Sintaxe
while (condicao) {
  // faça
}
